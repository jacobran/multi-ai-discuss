# 多 AI 议事助手

一个本地运行的多 AI 圆桌讨论工具。让多家大模型 AI 像微信群聊一样依次发言、互相补充、辩论交锋，帮你从多个视角深入分析问题。

## 功能特性

- 🗣️ **群聊串行模式**：AI 一个接一个发言，后一个能看到前面的回答再补充，像真实的圆桌讨论
- ⚔️ **辩论大赛模式**：AI 明确知道总轮次、当前轮次、还能发言几次，自动区分立论/交锋/总结陈词阶段
- 🛡️ **防跑偏机制**：第一轮独立发言 + 强化纠偏提示词 + 主题锚定，防止某个 AI 带偏整个讨论
- 💾 **实时保存**：每个 AI 发言完就自动保存到 Markdown 文件，讨论内容不会丢失
- 🔄 **继续讨论**：讨论结束后可以接着之前的内容继续深入，AI 能看到之前所有轮次的完整讨论
- 📁 **读取本地文件**：直接选择本地文件（代码、文档、方案等）作为讨论内容，不用复制粘贴
- ⚙️ **灵活配置**：支持 1-5 轮或不限轮次，可随时启用/停用某个 AI 席位
- 🔒 **本地运行**：所有数据保存在本地，API Key 只存在浏览器 localStorage，不上传任何服务器

## 系统要求

- Windows / macOS / Linux
- Python 3.8+（用于运行本地代理服务器）
- 现代浏览器（Chrome / Edge / Firefox）
- 至少一家大模型平台的 API Key

## 快速开始

### 1. 下载项目

```bash
git clone https://github.com/jacobran/multi-ai-discuss.git
cd multi-ai-discuss
```

### 2. 配置 API Key

双击 `启动工具.bat`（Windows）或运行 `python server.py`，浏览器会自动打开 `http://localhost:8787`。

进入「AI 席位设置」页，填入你自己的 API Key：

| 平台 | 免费 Key 获取地址 | 推荐模型 |
|------|-------------------|---------|
| 智谱 AI | https://open.bigmodel.cn/ | glm-4-flash（免费） |
| 阿里百炼 | https://bailian.console.aliyun.com/ | qwen3.7-plus（免费额度） |
| 火山豆包 | https://console.volcengine.com/ark/ | doubao-seed-2-1-turbo-260628（免费额度） |
| 月之暗面 | https://platform.moonshot.cn/ | moonshot-v1-8k |
| DeepSeek | https://platform.deepseek.com/ | deepseek-chat |
| OpenAI | https://platform.openai.com/ | gpt-4o-mini |

> 每家平台都有免费额度或免费模型，日常使用基本不花钱。

### 3. 开始讨论

1. 在「讨论」页填写**讨论主题**和**待讨论内容**（或点「读取本地文件」导入文件）
2. 选择讨论轮次（1-5 轮或不限）
3. 点「开始讨论」
4. AI 会依次发言，像微信群聊一样展示
5. 讨论结束后可以点「继续讨论」接着深入，或点「复制纪要」保存讨论结果

## 使用说明

### 辩论大赛模式

系统会自动告诉每个 AI：
- 本场讨论共几轮
- 当前是第几轮
- 在本轮第几个发言
- 还能发言几次

AI 会根据阶段调整发言策略：
- **第 1 轮（立论）**：亮出核心观点
- **中间轮（交锋）**：反驳、补充、深化前面的观点
- **最后一轮（总结陈词）**：归纳共识、指出分歧、给出最终结论

### 防跑偏机制

- **第一轮独立发言**：每个 AI 第一轮看不到其他 AI 的回答，避免从众
- **强化纠偏提示词**：明确要求 AI "如果前面的 AI 理解有误，请明确指出并纠正，不要盲从"
- **主题锚定**：每次发言都重复讨论主题，防止偏离

### 继续讨论

讨论结束后，按钮会变成「继续讨论」：
- 可以在输入框补充新的要求或问题
- 选择还要再讨论几轮
- AI 会从下一轮开始，能看到之前所有轮次的完整讨论
- 继续讨论的内容会覆盖保存到同一个文件，包含完整的所有轮次

### 实时保存

- 每个 AI 发言完就自动保存到 `讨论记录/` 目录
- 文件名格式：`YYYYMMDD_HHMMSS_主题.md`
- 同一场讨论（包括继续讨论）会覆盖保存到同一个文件
- 关闭浏览器或意外退出也不会丢失讨论内容

## 项目结构

```
multi-ai-discuss/
├── index.html          # 主页面（单文件，包含所有 UI 和逻辑）
├── server.py           # 本地代理服务器（托管页面 + 转发 API 请求）
├── 启动工具.bat         # Windows 一键启动脚本
├── 讨论任务.md          # 讨论任务模板
├── 讨论记录/            # 讨论记录保存目录（自动生成）
└── README.md           # 本文件
```

## 技术架构

- **前端**：纯原生 HTML/CSS/JavaScript，单文件，零依赖，无构建工具
- **后端**：Python 标准库 `http.server`，多线程，仅做静态托管和 API 代理
- **为什么需要代理服务器**：浏览器直接从 `file://` 协议请求外部 API 会被 CORS 拦截，本地代理转发可以绕过这个限制
- **数据存储**：AI 席位配置存在浏览器 localStorage，讨论记录保存为本地 Markdown 文件
